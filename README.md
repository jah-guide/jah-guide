# 🔭 Featured Projects

## 📈 [FlowGate](https://github.com/jah-guide/flowgate)

Ops / SLA workflow case study — intake → triage → dual approval with live SLA posture.

### Highlights

- Structured service-request intake and triage
- Manager / director multi-step approval path
- On Track / At Risk / Breached SLA visibility
- Full analysis pack in `docs/` (requirements, process, traceability)

## 🗺️ [SourceMap](https://github.com/jah-guide/sourcemap)

Data & integrations case study — systems inventory, field mappings, and change impact analysis.

### Highlights

- Multi-system catalog (HRIS, Payroll, LMS, CRM, DWH)
- Field-level source → target mappings
- Blast-radius view when a field changes
- Spec-first `docs/` pack with Mermaid diagrams

## 📊 [JournalX](https://github.com/jah-guide/journalx-dashboard)

A focused trading journal built around risk-to-reward—not money.

JournalX helps traders capture market ideas before execution, review outcomes afterward, and identify the conditions that create their edge.

### Highlights

- Before-and-after trade reviews with optional chart screenshots
- R-based performance tracking with no money or account-balance fields
- Daily journal markups for multiple pairs
- Append-only markup updates for accountability
- Trade history with setup, session, outcome, and review filters
- Analytics by pair, setup, and session
- Planned versus achieved reward and plan-adherence tracking

## 🧾 [CMCS](https://github.com/jah-guide/CMCS-Project)

Enterprise claim approval workflow — lecturer → coordinator → manager, with ASP.NET Core reference app.

### Highlights

- Role-based claim submission and approval
- Document upload and status tracking
- As-is / to-be process models and requirements traceability
- Full Systems Analyst documentation pack in `docs/`
